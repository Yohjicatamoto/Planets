# Solar System Explorer

A 10-page website about the solar system, styled like an old desktop computer.
Built with plain HTML, CSS and JavaScript.

## Pages

Home, Sun, Moon, Earth, Mercury, Venus, Mars, Jupiter, Saturn, Uranus

## Folders

- `css/` - `style.css` for the shared window look, plus one theme file per page
- `js/` - one script per page
- `images/` - planet photos (NASA, ESA and Wikimedia Commons)

Open `index.html` in a browser to view the site.
